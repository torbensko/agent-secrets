Secrets 0.1.0
=============

- Store development credentials for services such as Cloudflare, App Store Connect, Anthropic and OpenAI in your Keychain, synced through iCloud Keychain.
- Add credentials from presets or any website, and edit them in place.
- Tag credentials with projects and grant project folders access.
- Coding agents read the credentials for the folder they run in through a local MCP server. Every access is logged, without values.
- Check for signed app updates from the Secrets menu.

Requires macOS 15 or later.
